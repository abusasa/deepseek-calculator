# deepseek / budget

Неофициальный калькулятор: сколько стоит 2 000 ₸ (или любая другая сумма) в API DeepSeek. Переводит тенге в токены, книги, подкасты, договоры и дни работы в OpenCode.

Сайт: https://abusasa.github.io/deepseek-calculator/

## Что считает

- баланс после курса, 6% налога на пополнение и комиссии банка;
- токены на выход, вход без кэша и вход из кэша;
- 10 сравнений: книги, «Война и мир», «Гарри Поттер», подкасты, договоры, письма, задачи в OpenCode, видео, резюме, кодовые базы;
- дни работы в OpenCode в трёх режимах;
- итоговую таблицу цен Flash и V4 Pro (пик / офф-пик).

## Формулы

```
баланс = сумма / курс / (1 + налог) * (1 - комиссия банка)
стоимость = вход * цена входа + выход * цена выхода
микс = (пик + офф-пик) / 2
```

Цены DeepSeek на 5 ноября 2026, доллары за 1 млн токенов:

| Статья | Flash (пик / офф) | V4 Pro (пик / офф) |
|---|---|---|
| Вход, кэш-хит | 0.006 / 0.003 | 0.044 / 0.022 |
| Вход, кэш-мисс | 0.30 / 0.15 | 1.32 / 0.66 |
| Выход | 1.20 / 0.60 | 3.96 / 1.98 |

Курс: 452,91 ₸ за $1 (Нацбанк РК, 5.11.2026).

## Допущения

Оценки токенов приблизительные: 1 русское слово ≈ 2 токена, 300 страниц ≈ 75 тыс. слов. «Война и мир» ≈ 3,2 млн символов. Книга — черновик и одна редактура. Задача OpenCode — 12 запросов по 40 тыс. токенов входа и 1,5 тыс. выхода, 80% входа из кэша. В расчёте нет повторов, неудачных запросов, thinking-токенов, описаний инструментов, Search/Fetch и роста контекста внутри сессии.

Подробности и ссылки на источники — на самом сайте, в секциях «Тарифы» и «Минусы».

## Локальный запуск

Статические файлы, сборка не нужна:

```bash
python -m http.server 8080
# или
npx serve .
```

Открыть http://localhost:8080.

## Стек

HTML, CSS, ванильный JavaScript. Шрифты Google: Fraunces, Inter Tight, JetBrains Mono. Без аналитики, без куки, без бэкенда.

## Дизайн

Правила [taste-skill](https://github.com/Leonxlnx/taste-skill) и палитра/типографика [no-slop.ai](https://github.com/ontesseract/no-slop-ai). Без стоковых фотографий, выдуманных отзывов и скролл-анимаций.
